RAJASTHANI WEDDING GALLERY ASSETS

- gallery-background.png: approved decorative main gallery background. The heading and captions remain HTML text.
- gallery-arch-frame.png: transparent ornamental photo-frame overlay. The photo is rendered behind it and clipped to the inner arch opening.

To add/replace photographs later, edit the galleryImages array near the top of js/main.js. Set src to a relative path such as assets/images/gallery/couple-portrait.jpg, then update alt and caption. Keep category for the placeholder fallback when src is empty.

- gallery-background-mobile.png: tall portrait background used only on phones (700px and below); desktop/tablet continue using gallery-background.png.
